Agent Arena

A drawing that runs on physics. Agents hunt for a strategy idea, bind to it and forge it into an expert advisor, then take it to the middle of the arena where the reigning champion is standing. The numbers underneath decide who stays there.

What this is, plainly. The animation is a simulation — bodies, springs and collisions worked out on this page in your browser. It is a way to picture the search, not a window onto a market. No price, quote or account is being shown, and nothing on this page reaches a broker.

What the numbers are. Every figure in the table and the cards below comes from a backtest on historical price data. A backtest measures the past under one set of cost rules. It is not a forecast, it is not a record of trading, and it is not a promise about any account. Which agent holds the middle of the arena is worked out from those measured figures, so the picture follows the table — the table never follows the picture.

How the arena works

The physics

Nothing here is a scripted path or a CSS transition. Each body carries a mass, a position and a velocity, and the loop integrates it at a fixed step so the motion is the same whatever frame rate your screen runs at.

  • The well. The arena centre pulls on everything with a softened inverse-square attraction, so bodies fall inward and swing past rather than snapping to a point.
  • The fields. Strategy fields drift on their own and pull agents toward them the same way. An agent heads for the one with the strongest pull it can feel.
  • The forge. On capture, the agent and the field are joined by a spring with damping. You can watch the tether stretch, overshoot and settle — that oscillation is the spring doing real work, not a loop of frames.
  • The burst. When the forge finishes, the spring releases and throws particles that carry their own velocity, feel the well and run out of life.
  • The handoff. An agent that beat the champion in the measured test charges the centre and collides with it. The collision is resolved with a real impulse, so the champion gets knocked off its mark and has to settle back. If the challenger's measured result is the better one, it takes the centre and the old holder moves to an inner orbit.

Why a higher number does not always take the centre

An agent can post a better result per trade than the champion and still not be counted as having beaten it. Scoring higher on a few dozen trades is not the same as scoring higher, and the margin column in the table is where you can see the difference: it gives the gap in standard errors, which is how much the figure would be expected to wobble if the same idea were measured again on a different stretch of the same market. A gap inside that wobble is a gap this data cannot resolve, so the agent is marked not resolved, it does not charge the middle, and the champion keeps the centre. The arena follows the evidence, not the bigger number.

What it is not

It is not a feed, a chart, or a record of orders. The arrangement of the bodies is decided by the measured figures in the table; the animation is how those figures are drawn, and it would be the same drawing on a screen with no internet connection once the file is loaded.

If the measurement file cannot be read, this page says so and the table stays empty. It does not fall back to stand-in numbers.
