## Lessons baked in

- **iOS file viewer runs no JavaScript.** The `luxu-chat-demo.html` opened on Christian's iPhone rendered a blank hero because the whole welcome ran on JS. Demos go out as hosted page links opened in Safari — never `.html` attachments.
- **720px/96-frame loops ballooned past 2MB** on the high-entropy Luxu artwork — not shippable for a mobile chat hero. Keep phone-facing media small (proven: 512px, 64 frames at 12fps, quality 65, <1MB).
