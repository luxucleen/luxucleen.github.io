Luxucleen LLC › Explorer

Turn any GitHub repo into a map — and AI-ready context.

Paste a GitHub URL. Explorer draws the whole project as a visual tree, packs the code into an AI-ready digest you copy in one click, and lets you browse every file in your browser — all three at once. Free, no install, no sign-up. It runs entirely on your machine.

Trick: bookmark luxucleen.com/explorer/?repo=owner/name, or in any repo URL change github.com to luxucleen.com/explorer/#github.com. Private repos: add a read-only token (kept only in your browser).
