That is 289 times more expensive — and 303,863 tokens is 152% of a 200,000-token context window. Loaded the ordinary way, that one server does not fit in the model's head at all. There is no room left for your question.

An honest caveat we will not bury: prompt caching can cut the repeat cost of a stable prefix substantially, so the real bill is usually lower than the top row. It does not fix the other half of the problem — the window is still full, and what caching saves in money it does not give back in room to think.

Why it happens

To let an assistant use your tools, the usual approach hands it the manual for every tool up front: each name, each description, each parameter. Five ordinary apps run to tens of thousands of tokens. A large API runs to millions. Then every step of the work travels back through the model — fetch a row, return it, decide, fetch the next.

Cloudflare published the same arithmetic for their own API: 2,594 tools ≈ 1,170,000 tokens as ordinary tool definitions. Rebuilt so the assistant writes code instead, the whole API fits in two tools and about 1,000 tokens. Anthropic arrived at the same pattern independently.

What to do instead

  • Hand over names, not manuals. The assistant sees what exists and asks for the details of the one tool it needs. That single change is the 289× above.
  • Let it write a script, not forty messages. One piece of code does the whole errand in a sandbox; only the answer comes back. Models are far better at writing code than at conducting forty round trips.
  • Keep the keys outside the sandbox. The code should never see a credential — the supervisor holds the tokens and injects them.
  • Do not let code execution stand in for permission. Cloudflare says this plainly and so do we: a sandbox decides what can run, never what is allowed to. Authorisation stays in the tool handlers.

Repeat our measurement

Point this at your own tool catalogue. If your numbers differ from ours, yours are the ones that matter — that is the point of measuring.

import json, tiktoken
enc  = tiktoken.get_encoding("cl100k_base")
tools = json.load(open("your-mcp-catalog.json"))

defs  = [json.dumps({k: t[k] for k in ("name","description","inputSchema") if k in t})
         for t in tools]
print("loaded up front :", sum(len(enc.encode(s)) for s in defs))
print("names only      :", len(enc.encode(", ".join(t["name"] for t in tools))))
